Privacy Policy

Last updated: 2026-06-04

This application is a personal financial management tool that connects to bank accounts through Enable Banking in order to retrieve account information and transactions.

Data We Access

With your explicit consent, this application may access:

  • Account balances
  • Transaction history
  • Account metadata (e.g. account name and currency)

How Data Is Used

All financial data is used solely for personal budgeting and financial tracking within the application. Data is not used for profiling, advertising, or resale.

Data Sharing

Data is shared only with Enable Banking as required to provide account connectivity. No data is shared with third parties beyond this integration.

Data Storage

Financial data may be stored locally on the server running this application. It is not transmitted to external services except Enable Banking APIs.

Contact

This application is maintained for personal use. For questions, contact the system owner directly.
